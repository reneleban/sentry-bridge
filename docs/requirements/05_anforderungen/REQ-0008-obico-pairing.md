# REQ-0008: Obico pairing flow

## Description

The system shall implement an Obico pairing flow: generate a 5-character pairing code and poll for server confirmation.

## Rationale

Not documented.

## Acceptance Criteria

- The setup wizard displays a pairing code.
- After the user links the printer in Obico, the wizard advances automatically within 60 s.
