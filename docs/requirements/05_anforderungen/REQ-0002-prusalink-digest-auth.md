# REQ-0002: PrusaLink connection with Digest Auth

## Description

The system shall connect to the PrusaLink HTTP API using HTTP Digest Authentication.

## Rationale

Not documented.

## Acceptance Criteria

- A connection test to a live PrusaLink endpoint with valid credentials returns HTTP 200.
- Invalid credentials return a connection error reported to the user.
