# REQ-0009: Setup wizard

## Description

The system shall provide a browser-based setup wizard (4 steps: PrusaLink → Camera → Obico Pairing → Done) that guides a first-time user to a fully configured state.

## Rationale

Not documented.

## Acceptance Criteria

- A user with no prior configuration can complete the wizard and reach a functioning bridge state in under 10 minutes.
